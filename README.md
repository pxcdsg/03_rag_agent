# 03_rag_agent

一个循序渐进的 RAG 项目。第一阶段只完成文档读取和文本切块，后续再加入向量检索、引用来源和对话界面。

## 第一阶段功能

- 读取 `documents/` 下的 `.md` 和 `.txt` 文件
- 把长文本切成长度固定的文本块
- 相邻文本块保留一部分重叠，避免上下文被切断
- 为每块记录来源文件和块编号

## 运行

```powershell
python main.py
```

## 后续阶段

1. 生成 Embedding
2. 根据问题检索相关文本块
3. 把检索结果交给大语言模型
4. 输出引用来源
5. 增加 FastAPI 或 Streamlit 界面
